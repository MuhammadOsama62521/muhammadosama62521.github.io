01 — Expertise

What I do

The disciplines I work across, and what each one delivers.

Penetration Testing & Red Teaming

Authenticated and unauthenticated testing across IT infrastructure, internal and external networks, and web applications — findings with reproducible steps, honest impact ratings, and a retest to confirm the fix held. On red team engagements the question shifts from what is vulnerable to whether an objective can be reached without being caught: adversary emulation mapped to ATT&CK techniques, run against the controls and the SOC that are meant to stop it.

  • IT infrastructure
  • network
  • web application
  • adversary emulation

Digital Forensics Investigation

Investigating incidents after the fact — sound evidence acquisition and handling, disk and memory analysis, and timeline reconstruction that answers what happened, how far it went, and what was taken.

  • evidence handling
  • disk & memory analysis
  • timeline analysis

Cyber Crime Investigation

Cases where the subject is a person rather than a system — online fraud, intellectual property theft, insider activity. Tracing anonymous actors back to verifiable identities, documenting what they did in a form that survives scrutiny, and packaging the result for the client, their legal team or law enforcement.

  • attribution
  • OSINT
  • evidence handling
  • case reporting

Security Assessments & Audits

Structured review of an environment against a defined baseline. Configuration and control gaps documented with severity, business impact, and a remediation plan sequenced by what actually reduces risk first.

  • gap analysis
  • configuration review
  • remediation tracking

Secure Software Development

Building security into the delivery process rather than auditing it in afterwards — threat modelling at design time, secure code review, and remediation guidance developers can act on without rewriting the product.

  • SSDLC
  • secure code review
  • threat modelling

Cloud & Infrastructure Security

Reviewing cloud and on-premise estates for exposure — over-permissive identity and access, weak segmentation, unhardened baselines, mishandled secrets — then implementing the fixes rather than only listing them.

  • cloud posture
  • hardening
  • identity & access

Malware Analysis & Ransomware DFIR

Client Work

Incident response on live malware and ransomware compromises — acquiring evidence from running systems, reversing the sample in isolation, and establishing how far the infection had actually reached.

  • Delivered 12 malware analysis and ransomware DFIR engagements, each taken from a live compromised system through to a documented account of what the malware did and how far it spread.
  • Captured live images of affected operating systems and analysed them in an isolated VM, preserving the volatile state that an ordinary shutdown would have destroyed.
  • Reconstructed malicious activity from event logs, running processes and the API calls the sample made, then reverse-engineered the malware itself to recover behaviour that static indicators alone would have missed.
  • Identified the command-and-control domains the malware was communicating with, and scoped the compromise — which systems were affected, and how deeply.

Software Piracy & Licence Abuse Investigation

Investigation

Traced the individuals reselling a client's software under cracked licences, then closed the weakness that made the cracking possible in the first place.

  • Identified and attributed two individuals reselling the client's software with bypassed licensing, building a picture that tied them to the businesses, financial accounts and location they were operating from.
  • Captured evidence of the bypassed software actually running, confirming the licence circumvention rather than inferring it from sales listings.
  • Traced the circumvention to a vulnerability in the client's own licence management system — moving the finding from "someone cracked our product" to a specific, fixable defect.
  • Delivered the remediation. The client now runs a hardened, centrally managed licensing system, closing the route that made the original cracking possible.

Online Fraud Investigation

Investigation

Investigated a drop-shipping fraud that had already cost a client a substantial sum, and traced the operator running it.

  • The scheme spanned three separate websites — one to place orders, one showing them being processed and shipped, and one presenting a wallet balance the client believed they were earning.
  • Established that all three were a single fabricated ecosystem, hosted by the same operator in the same environment, built purely to make the arrangement look legitimate and the returns look real.
  • Traced the operator and the bank accounts being used to collect payments from the victim.
  • Compiled a detailed investigation report and referred the case to the relevant authorities.
